🎣 钓鱼（Fishing）

  1. 找 Vanya 在河流码头解锁钓鱼爱好，获得第一根钓竿
  2. 河流和海洋鱼种不同，注意区分钓点
  3. 工具耐久下降后使用修复包，不要重新制作
  4. 找 Bill 解锁海钓活动，与其他玩家一起参与可获额外奖励
  5. 钓到的鱼可以直接送给 Vanya 提升好感度，也可以卖给 Albert Jr. 换金币

🌱 园艺（Gardening）

  1. 找 Blanc 在园艺商店解锁，获得初始种子和浇水壶
  2. 在自家地块种花种菜，花卉可美化庭院
  3. 部分植物是烹饪食材，园艺与烹饪爱好可联动
  4. 与 Blanc 对话时注意他头上的鸟，可同时积累观鸟经验
  5. 好感度提升后 Blanc 店内解锁更多高级种子

👨‍🍳 烹饪（Cooking）

  1. 找 Massimo 解锁，从 Ka Ching 杂货店购买基础食材
  2. 多放几个炉子同时烹饪，效率翻倍
  3. 食谱随 Massimo 好感度逐步解锁，优先提升他的好感
  4. 雨天找 Doris 购买特殊食谱（如原味卷蛋糕），需要许愿星
  5. 烹饪成品可以送给 Massimo 提好感，也可以卖给 Albert Jr.

🦋 捉虫（Bug Catching）

📷 观鸟（Birdwatching）
