新手入门

🌱 开局第一周该做什么

  1. 完成新手主线任务，解锁开发者公会（D.G.）等级系统，许多功能需要公会等级解锁
  2. 每日登录领取签到奖励，积攒免费货币和材料
  3. 与镇上 NPC 交谈，接取委托任务，获取建造材料和贡献勋章
  4. 选定 1–2 个爱好优先发展，不要贪多，工具耐久有限
  5. 修复工具时使用修复包，避免重新制作浪费资源
  6. 雨天务必出门找隐藏 NPC Doris，她只在特殊天气出现，售卖稀有食谱
  7. 尽早找到 Andrew 解锁骑行，移动速度大幅提升
💡 新手重点：公会等级（D.G. Rank）决定可解锁的玩法内容，优先通过日常委托和活动提升，不必花钱。
🏗️ 家园建造是 Heartopia 最核心的玩法。随时可以推倒重来，不用怕做错！建议先锁定"框架"，再摆家具。

联机建造解锁

D.G. 等级 8

  1. 初始拥有 3 个地块，提升 D.G. 等级逐步解锁新地块，每次扩建需要支付金币和指定建材
  2. 找 Bob（建筑师）确认当前扩建费用，不同等级所需材料不同
  3. 扩建前规划好整体布局方向，扩建后可拆除现有墙体打通空间
  4. D.G. 等级 8 解锁联机建造，可邀请其他玩家一起装修
  5. D.G. 等级 27 解锁互动家具升级，可获取普通商店没有的专属套装家具

建造技巧

💡 实用建造技巧

  1. 优先用俯视图（Top View）进行家具摆放，比第三人称视角清晰得多
  2. 先锁定框架（墙壁、楼梯、地板），再放家具；结构调整比重新布置家具更省事
  3. 放置楼梯后在上方铺地板，即可创建第二层；叠加多层可做阁楼或屋顶平台
  4. 外墙也可以装饰，院子 / 花园同样是展示空间，不要只专注室内
  5. 完成建造后存档为蓝图（Blueprint），可随时回滚，也可导入社区蓝图
  6. 不用的家具不要删除，放入仓库备用，日后可组成套装获取额外加成
  7. 蓝图气泡每天重置，在城镇广场、温泉悬崖、渔村、神奇森林等地随机刷新，每日出门巡逻捡气泡
🎨 同一件家具可以被染色个性化，工作台制作好图案后应用即可。叠放地毯、在桌上摆小物件、墙面挂装饰都能增加空间层次感。
🎖️ D.G.（开发者公会）等级是游戏的主进度条，几乎所有核心功能都需要它解锁。免费玩家和付费玩家每日可获勋章数量相同，稳定日常比氪金更重要。

体力（Energy）管理

⚡ 体力系统说明

体力条示意（每日重置后满格）

🪓 砍树 · 🎣 钓鱼 · ⛏️ 挖矿 消耗体力；步行 · 对话 · 建造 不消耗体力

  1. 每日 6:00 AM 服务器重置时体力完全回满，安排高消耗活动在重置后进行
  2. 体力低于 20 时无法奔跑，只能慢走；可以骑车代步维持效率
  3. 吃食物快速回复体力——基础混合果酱（Mixed Jam）回复 22 点，高级料理如松露蘑菇派回复量可观
  4. 睡觉是最省事的被动回复方式，下线前让角色上床睡觉
  5. 体力耗尽时可以继续做不消耗体力的活动：摆家具、与 NPC 对话、逛商店

🎣 钓鱼（Fishing）

  1. 找 Vanya 在河流码头解锁钓鱼爱好，获得第一根钓竿
  2. 河流和海洋鱼种不同，注意区分钓点
  3. 工具耐久下降后使用修复包，不要重新制作
  4. 找 Bill 解锁海钓活动，与其他玩家一起参与可获额外奖励
  5. 钓到的鱼可以直接送给 Vanya 提升好感度，也可以卖给 Albert Jr. 换金币

🌱 园艺（Gardening）

  1. 找 Blanc 在园艺商店解锁，获得初始种子和浇水壶
  2. 在自家地块种花种菜，花卉可美化庭院
  3. 部分植物是烹饪食材，园艺与烹饪爱好可联动
  4. 与 Blanc 对话时注意他头上的鸟，可同时积累观鸟经验
  5. 好感度提升后 Blanc 店内解锁更多高级种子

👨‍🍳 烹饪（Cooking）

  1. 找 Massimo 解锁，从 Ka Ching 杂货店购买基础食材
  2. 多放几个炉子同时烹饪，效率翻倍
  3. 食谱随 Massimo 好感度逐步解锁，优先提升他的好感
  4. 雨天找 Doris 购买特殊食谱（如原味卷蛋糕），需要许愿星
  5. 烹饪成品可以送给 Massimo 提好感，也可以卖给 Albert Jr.

🦋 捉虫（Bug Catching）

  1. 找 Naniwa 在森林地带解锁，获得初始捕虫网
  2. 不同昆虫在不同地点和时段出现，注意时机
  3. 稀有昆虫标本送给 Naniwa 好感度加成最高
  4. 完成图鉴有额外奖励

📷 观鸟（Birdwatching）

  1. 找 Bailey J 在公园/自然区域解锁，获得望远镜
  2. 特定地点和时段发现不同鸟类，耐心等待
  3. 拍到高质量鸟类照片送给 Bailey J 提好感
  4. 也可通过与 Blanc 对话顺带积累观鸟经验（他头上有鸟）

🎵 音乐演奏

  1. 在自家或公共区域找到钢琴等乐器即可演奏
  2. 社区里有玩家分享的乐谱，可以学习
  3. 也可自由创作，完成后可与其他玩家分享
